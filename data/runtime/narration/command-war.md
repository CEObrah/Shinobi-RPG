# Command and large-war narration
Narrate the command picture Wei actually has: visible units, sensor/scout reports, messengers, signals, terrain, reserves, support, casualties, and delay. A subordinate command group is one reporting node but its commander remains a real person. Command overload appears as queued messages, slow reserve response, contradictory movement, lost awareness, or increased reliance on subordinate initiative, never as a magical debuff to soldier bodies. Ordinary units remain aggregate statistical actors; wake exact detail only where named people, specialists, jutsu, terrain, equipment, or close thresholds matter.
