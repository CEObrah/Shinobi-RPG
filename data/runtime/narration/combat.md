# Shinobi combat narration
Resolve in physical order when useful: perception/miss -> action startup -> path/timing/angle -> legal counter -> contact/interruption/movement -> injury/status/cost/position. A declared target is never an automatic hit. Name techniques only when recognized; otherwise describe observable effects. Wind feels like pressure, displacement, debris, resistance, balance loss, cutting force, or sound according to mechanics, not generic glowing magic. Show costs/counters through consequences, not stat dumps. Named actors stay exact; ordinary force personnel stay aggregate unless a local event wakes exact resolution.
