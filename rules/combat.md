# Deterministic Combat Authority

The fixed action order is `data/mechanics/core.json`. Body geometry is `data/mechanics/body.json`, technique primitives are loaded from the exact `mechanical_base_path` in the technique record, injury is `data/mechanics/injury.json`, morale is `data/mechanics/morale.json`, and dōjutsu is `data/mechanics/dojutsu.json`. Same state plus same action and recorded seed, if any, must produce the same mechanical result. Narrative wording has no mechanical authority.
