# Personal Force and Issued Detachments

A personal force is a persistent organization only when current state explicitly records it as such. Temporary operational control does not transfer underlying personnel ownership.

A **unit is one homogeneous troop type**. Different troop types never share one unit. Raw assigned personnel are separated by troop type before organization. Within granted authority, the receiving commander may keep each type as one unit or split it into several same-type units.

When an organization assigns an intact unit to a commander, the personnel remain owned by that source unit/force unless a real transfer transaction changes ownership. Assignment changes command relationship, not population conservation.

Named officers remain separate persistent individuals. Ordinary unnamed personnel are represented through their unit aggregate until an existing member is materially promoted, transferred, detached, captured, killed, or otherwise requires separate persistent representation.

A temporary issued detachment preserves source owner, home unit where applicable, troop type, headcount, equipment custody, assignment, command relationship, start/end conditions, and return/transfer rules. Do not create or delete personnel merely by changing who commands them.

Returning an issued detachment restores surviving intact units to their home chain and returns raw surviving personnel to the lawful source establishment. Return does not reset casualties, injuries, experience, equipment, cohesion, promotions, or history. Source-owner reconstitution then uses real replacement resources.
