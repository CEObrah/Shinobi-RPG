# Tests

Release-blocking deterministic regression inputs for the current canonical release. `tools/audit.py`, `tools/test_development.py`, and `tools/test_mechanics.py` must all pass on the packaged release.

Static canon continuity, provenance, visibility routing, anchor gating, and negative source fixtures are validated by `tools/test_canon.py`. An unbound anchor lawfully requires an empty canon history pack.

Mutable executable fronts are validated by `tools/test_canon_fronts.py`: stable migrated identity, non-forcing conditional stakes, explicit unknown fields, truth/visibility/knowledge separation, append-only chronology, and exact one-process frontier equivalence.

Family lifecycle architecture is validated by `tools/test_family.py`: sparse authority, player-agency gates, union/household/parentage/succession references, routing, and no duplicate family clock.
