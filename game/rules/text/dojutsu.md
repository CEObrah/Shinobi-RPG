# Dōjutsu Authority

Authoritative formulas and capability tables are in `game/data/mechanics/dojutsu.json`; eye ownership is resolved through the compact `state/medical/ocular-registry.json` index, then the exact owner shard or linked stockpile inventory. The index is routing only; exact eye records/stockpile state own custody. Narrative prose may not override those records. Every eye is a conserved biological object. Integration is eye-recipient compatibility, Ocular Control is user skill for the dōjutsu family, and Feature Mastery is capability-specific skill. Native dōjutsu eyes have Integration 200 unless injured. A non-Uchiha Sharingan cannot biologically revert to a normal eye, but passive drain follows the registered formula and reaches exactly zero at Integration 200 plus Ocular Control 200. Active abilities still pay registered costs.


## Conserved stockpile batching

Homogeneous stored biological assets may use a deterministic conserved batch rather than repeating identical full records. The batch must preserve a unique ordinal namespace, exact count, shared physical prototype, available ordinal ranges, and a deterministic materialization/allocation rule. Selecting or transferring one asset first materializes that exact ordinal, removes it from the available range, and never regenerates it. Batching changes storage only, never inventory quantity, capability, custody, or transplant success.
