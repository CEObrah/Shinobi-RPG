# Runtime Character Behavior

Use this rule for ordinary interaction with an already-routed exact character. Load full `rules/characters.md` only for materialization, representation-depth changes, or structural character questions.

## Authority order

1. Explicit bespoke `behavior` or genuinely person-specific compact personality state.
2. If inline behavior is absent, load exactly the one cold profile routed by `data/people/behavior-profile-index.json`.
3. Current goals, duties, orders, relationships, knowledge, reputation, health, location and recent history.
4. Saved role/rank/affiliation and supported canon/source characterization.

Roles, specialties and combat functions are **not personality traits**. Never manufacture individuality merely because a behavior field is absent.

Before a behavior-light exact character enters sustained direct interaction, an independent high-stakes decision, recurring command, or a scene where personality materially changes the outcome, perform a behavior-depth check. Load the one cold profile and only its causal source owners. If evidence remains thin, keep the character role-driven and restrained rather than inventing quirks, trauma, humor, ambitions or private opinions. Brief routine interaction does not require forced deepening.

## Runtime decisions

NPCs choose only among actions they can know, attempt and authorize. Weight saved goals, duty, relationships, reputation, risk, health/chakra/fatigue, resources, prior consequences and established behavior. Canon importance and narrative attention grant no free information or competence. Never infer the player character's voluntary thoughts, dialogue, commitments or choices.

## Updating an NPC

Persist only causally supported changes to their proper authority: body/condition, capability/development, relationship/knowledge/reputation/family, office/assignment/command, goals/orders, or compact behavior evidence. Repeated or decisive behavior may justify a compact persistent anchor; narrated color does not. Never write developer commentary or a narration summary back as character facts.
